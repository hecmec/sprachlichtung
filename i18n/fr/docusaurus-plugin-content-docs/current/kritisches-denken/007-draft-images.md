## Catalogue d'images

<!--t src=026ca692-->
Toutes les images réutilisables sous `static/img` (servies depuis `/img/…`) ainsi que
les images situées dans l'arborescence `docs/`, regroupées par dossier. Utilisez le
sélecteur de taille pour changer l'aperçu, filtrez par chemin, et cliquez sur **Copy**
pour obtenir un lien prêt à coller dans une page markdown (par ex. `![alt](/img/kd/foo.png)`).
